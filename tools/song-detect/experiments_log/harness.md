# 트랙 harness 실험 로그

브랜치 proto/sd-harness, 작업 위치 tools/song-detect/harness/. 원시 결과는 cache/proto_harness/ (메인 cache 의 하위 폴더, 다른 산출물은 안 건드림).
표기: 가설 -> 설정 -> 지표(전/후) -> 판정(채택/기각/보류). 시간은 이 PC(CPU 20스레드) 실측 초.

## 축 (a) 단계 매니페스트 (harness/manifest.py, exp_a.py, scene_probe.py)

구현: 단계(final / sig / scene / route)마다 키 = 해시(코드 AST + 입력 파일 해시/서명). 코드 해시는 주석/독스트링을 뺀 AST라 주석만 고치면 stale 이 아니다.
sig(bursts, rel_db)와 scene 은 후보(경계 0.1초 반올림) 단위로 재사용한다. route 키에는 이 방송에 해당하는 등록부 항목만 넣는다. 처음 전체 실행이 현행 결과와 같은지 먼저 확인했다:
3_final.json 61/61 동일, 카드 191/191(등급, 사유, likely, weak, 경계) 동일.

## 축 (c) 학습형 랭커 (harness/ranker.py, venv python)

데이터: cache/audit/signals.csv 163행(라이브 88 = blind5 8, blind6 27, blind78 4, blind9 49 / N 75, 그중 blind9 N 55). 특징 18개(오디오: speech, bursts_per_min, sing_std, rel_db, sing, music, sp_mid_frac, nospeech_max_frac, ctx_speech, speech_frac / 화면: tstd, blk, moving_frac, static_frac, diff_med, cut_frac, bright_px / 길이). 장면 풀 거리(scene, d_live)는 누수라 뺐다.
평가: 그룹 hold-out(스트리머 x 방송일 LOGO 50그룹, 그 외 스트리머 단위 11그룹). 노출 = veto 안 걸림 AND p >= 임계. veto = 구조 규칙(레이아웃 watch/idle) 또는 tstd > (학습 라이브 최댓값 + 0.01).
임계: p05 = 고정 0.5 / q0 = 학습 그룹 5겹 안쪽 교차검증으로 얻은 학습 라이브 p 의 최솟값(학습 라이브 손실 0 목표) / q5 = 5% 분위. 비교선은 logo_route 의 규칙(C: tstd 재추정, D: C + 신호 선택, m=여유).
표기: N 노출 a/55 = blind9 N 55 중 완성본에 노출, 손실 b/49 = blind9 라이브 49 중 숨김 (괄호는 라이브 88 전체).
