# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a light/dark mode toggle button to the toolbar that instantly switches the app theme and persists the preference in config.json.

**Architecture:** Extract the existing QSS stylesheet from `mainGUI.py` into `gui/theme.py` alongside a new dark theme string and an `apply_theme()` function. `MainWindow` reads the saved preference on startup and applies it; a toolbar button lets the user switch themes at runtime.

**Tech Stack:** Python 3, PyQt6 QSS stylesheets, existing `module/data_manager.saveConfig()`

---

| File | Action | Responsibility |
|------|--------|----------------|
| `gui/theme.py` | **Create** | `LIGHT_THEME`, `DARK_THEME` QSS strings + `apply_theme(app, is_dark)` |
| `gui/mainGUI.py` | **Modify** | Import `apply_theme`, add toolbar toggle button, apply theme on startup, remove inline `app.setStyleSheet()` |
| `gui/add_channel_dialog.py` | **Modify** | Remove local `self.setStyleSheet()` (disabled-widget styles now live in theme.py) |
